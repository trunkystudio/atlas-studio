# Contributing to Atlas Studio 0.1

Contributions, bug reports, accessibility feedback and improvement ideas are welcome.

Open an issue with what you expected, what happened, your app/Windows version and steps to reproduce. Remove private writing and personal information from screenshots and attachments.

For code contributions, discuss substantial changes in an issue first, keep changes focused, run npm test and npm run build, and include relevant validation in the pull request. Preserve offline use, accessible controls, local data safety and the clean interface. Do not add AI writing or cloud dependencies without prior discussion.

Reports and contributions will be reviewed for future updates. Accepted improvements will be included when ready; submission does not guarantee implementation or a release date. Contributors and helpful reporters can be acknowledged in future release notes with their permission.
