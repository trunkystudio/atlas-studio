Start here

Your first session

Choose a starting point for any kind of writing.

Where to find it
First launch; Atlas Studio menu → Help & Learning

  1. Choose A fresh page for an empty project, Show me around for a practice project and quick tour, or Continue with my existing library when that option appears.
  2. Use New to create ordinary editable writing. You can write fiction, fan fiction, an article, an essay, a letter, poetry, research or another kind of text in the same project.
  3. Open Help & Learning whenever you need instructions. Choose a short tour, resume a paused one, or search for the task you want to do.
  4. For hands-on learning, choose Create practice project in this center. It adds separate sample material and never resets your existing work.
What you should see

You have a place to write and can choose how much guidance to see.

Helpful details

  • Templates suggest a starting structure; they never restrict your subject or audience.
  • Replaying a tour does not create another project. The practice-project button reopens its existing project if it is still present.

Start here

Find your way around

Understand the title bar, sidebar, main area and optional panels.

Where to find it
The main Atlas window

  1. Use the Atlas Studio name/logo at the top left to open the application menu. It contains import, library, backup, preferences and help actions.
  2. Choose a project or document in the left sidebar. The main area displays your writing or the selected workspace view.
  3. Use Back and Forward above the workspace, Alt Left/Right, or mouse navigation buttons to revisit locations. Recent locations offers the last 20 distinct entries from this session. Opening another library resets the navigation history.
  4. Use the top toolbar for Writing tools, search, focus, details, Export and New. Hover an icon for its name; keyboard focus also reveals an outline.
  5. Open the details panel only when needed. Drag the sidebar separator to resize it, or focus the separator and use arrow keys. Preferences retain your panel choices.
  6. Use the window controls to minimize, maximize/restore or close Atlas. Closing waits for saving; if saving fails, Atlas offers ways to keep or rescue your draft.
What you should see

One sidebar and one main work area keep navigation predictable.

Helpful details

  • The project name in the title bar tells you where you are.
  • F1 opens this guide; Ctrl K searches the library.

Projects and library folders

Create, select and locate your work.

Where to find it
Projects in the sidebar; Atlas Studio menu → Choose library folder

  1. Use the plus button beside Projects to create a project. Give it a name, color and optional writing intention/deadline, then save.
  2. Select its name to limit the workspace to that project, or choose All projects to see writing across the library.
  3. Edit a project through its sidebar controls. Document details can change the project for an item and its descendants.
  4. For a different library on disk, use Choose library folder. Save current work first and select the intended folder. Preferences → Open library folder shows the current location.
What you should see

Projects group related writing; a library is the on-disk collection containing all those projects.

Helpful details

  • Project folders in the tree are organizational items inside a project, not Windows directories.
  • Existing installations normally retain the legacy %APPDATA%\Folio Studio location.

Format notes and limits

  • Use one Atlas instance to write a given library. Library files are local and are not encrypted by Atlas.

Document tabs and reading memory

Switch drafts without losing your place.

Where to find it
Tab strip above Writing

  1. Open a document from the sidebar or search. It appears in the tab strip; selecting a tab returns to that document.
  2. Hover or focus a tab to reveal its pin and close buttons. Pinned tabs stay first; a tooltip includes the project when titles match.
  3. Close a tab with its X or Ctrl W. Use the reopen-arrow button or Ctrl Shift T to reopen a recently closed tab. Closing a tab does not delete the document.
  4. Use Ctrl Tab / Ctrl Shift Tab to cycle tabs. On a focused tab, arrow keys, Home and End move between them.
  5. Return to a draft to restore cursor/selection and scroll. The PDF reader remembers its own page and zoom.
What you should see

You can move between drafts and sources while keeping your position.

Helpful details

  • The sidebar pin/filter is a bookmark for writing; tab pinning controls the open tab strip.

Writing & review

Writing and selection formatting

Format a passage without a crowded permanent ribbon.

Where to find it
Writing editor; toolbar near selected text

  1. Choose Outline in the editor toolbar to show headings. Select a heading to place the cursor there. A warning marks skipped heading levels. Collapse hides descendant headings in the outline, without hiding or changing the writing.
  2. Hover or focus an outline row for Move up/down controls. A move includes its text, images and all subsections, and can be undone in one step. Moves stay among sibling headings; headings nested inside tables or lists cannot be moved here.
  3. Click the draft and type. Select a passage to reveal bold, italic, underline, highlight, comment, link and list controls beside it.
  4. Use Paragraph style above the editor for paragraph or heading levels 1–3. Headings also build the outline in document details.
  5. Use Insert for bullet/numbered lists, checklists, quotes, code blocks, dividers, tables, images, links and equations.
  6. Use Ctrl B / Ctrl I for common formatting and the undo/redo buttons for editor changes. Word and character counts appear below the draft.
  7. Right-click a misspelled word for local suggestions or Add to personal dictionary. Set the language in Language & accessibility.
What you should see

Your draft has readable structure with formatting close to the text.

Helpful details

  • Blank writing remains unrestricted across purposes.
  • Word segmentation varies by language, so treat counts as a writing aid rather than linguistic certification.

Where to find it

Images and web links

Bring local illustrations and external references into your writing.

Where to find it
Writing → Insert → Image or Link

  1. For an image, choose Insert → Image, add a local file if needed, then select its thumbnail. Atlas stores the research attachment with the library.
  2. Keep meaningful filenames so images are easy to identify on the research shelf. Complete backups include the stored bytes.

Images and links support the writing while remaining locally organized.

  • External websites open separately and may require a network. Word uses a placeholder for WebP; supported raster images export normally.

Locate a word and revise individual or repeated occurrences.

Where to find it
Ctrl F; Find and replace toolbar button

  1. Open the document and press Ctrl F. Enter Find text and, if needed, Replacement text.
  2. Choose Match case when capitalization should matter. Next match selects the first occurrence, then advances through the document.
  3. Use Replace for the current occurrence or Replace all for every match in this document.
  4. Review the draft and save. For selected documents across a project, use Find & replace across writing instead.
What you should see

A focused replacement changes only the current document.

Helpful details

  • The search is literal text; it is not a regular-expression editor.

Comments and annotations

Keep revision notes beside a passage.

Where to find it
Selected-text comment button; Ctrl Alt M; Writing tools → Comments & annotations

  1. Select the passage before opening Comments if you want an anchored note. Without a selection, the comment applies to the document generally.
  2. Type Your comment and choose Add comment. The comment text is stored separately from the draft.

Revision reminders remain connected without becoming part of your prose.

  • Comments are retained in Atlas backups; exports do not create native Word review-comment objects.

Writing & review

Revision history and passage comparisons

Keep checkpoints and restore only the writing you need.

Where to find it
Document options → Save revision checkpoint; Writing tools → Compare revisions

  1. Before a major rewrite, save a revision checkpoint from Document options. Revision history also provides Checkpoint now and earlier saved drafts.
  2. Open Compare revisions and choose Earlier draft. Read the highlighted word changes and the earlier/current passage blocks.
  3. Choose Restore this passage for the block you want back. Atlas checkpoints the current draft first so the newer writing remains in history.
  4. For a whole earlier draft, open Revision history, review its preview and use its restore action.
  5. Check the resulting writing before continuing. Up to 60 checkpoints are retained per document.
What you should see

You can recover earlier writing while preserving the newer checkpoint.

Helpful details

  • A separate complete backup protects the whole library, not only one draft.

Format notes and limits

  • Passage restoration works with paragraph/content blocks, not arbitrary character-range merge editing.

Writing & review

Free offline speech-to-text

Turn your voice or a local recording into text, then review before insertion.

Where to find it
Ctrl Shift D; Writing tools → Offline dictation

  1. Open a writing document and Offline dictation. Choose the spoken language or Detect automatically.
  2. Choose Start recording only when you want microphone capture. Stop & transcribe ends capture and runs the bundled local speech model.
  3. Alternatively, choose Transcribe audio file and select a supported local recording. Keep it under 100 MB and five minutes after decoding.
  4. Review and correct the transcript. Place the writing cursor and choose Insert reviewed transcript. You can continue typing while transcription runs.
  5. Use Cancel transcription if needed. Advanced can import a compatible Whisper GGML model for another speed/accuracy tradeoff.
What you should see

Speech becomes reviewed text in your draft with no account or per-use fee.

Helpful details

  • The full installer bundles multilingual Whisper Small Q5 and a CPU runtime. Recognition is optional; there is no AI writing or rewriting.
  • Recording starts only with Start. Temporary native input/output files are removed after the job; a crash may leave SpeechTemp files locally.

Format notes and limits

  • Recordings are limited to five minutes. Closing the panel stops/cancels its job; uninserted review text is temporary. Recognition may make mistakes. Microphone access depends on your Windows device/privacy settings.

Folders, chapters and scenes

Build a nested structure and arrange it in the order you need.

Where to find it
Sidebar item menu; document details → Parent section

  1. Use a row’s menu to create a folder, chapter or scene inside it. Expand/collapse arrows reveal or hide the children.

  5. Use Manuscript’s reorder controls as a keyboard alternative. Check the resulting outline before exporting.
What you should see

Your nested outline controls reading and collected export order.

Helpful details

  • Pinned filters retain the parent path to pinned writing.
  • Use the bulk tool for selected items across a larger move.

Organize your work

Organize several items together

Move, tag, archive, restore or export a selection.

Where to find it
Writing tools → Organize selected items

  1. Choose the project and select the items you want to organize. Review the selection before applying an action.
  2. Choose the Bulk action. Move uses a destination; tagging uses the supplied tags; archive hides selected work from ordinary views without trashing it.
  3. Apply to selection. Folder/subtree actions include descendants, and invalid destinations inside the selection are rejected.
  4. To bring archived work back, enable Show archived items, select it and choose restore. Restoring nested writing also restores its archived parent path.
  5. Choose export to open export options for the selection. Folder containers are omitted from the actual writing output.
What you should see

Related items can be managed consistently in one operation.

Helpful details

  • Use status:archived in Ctrl K to locate archived writing.
  • Archive and trash are separate states.

Format notes and limits

  • Advanced clipboard cut/paste and a complete tree keyboard-command system are not included.

Organize your work

Preview project-wide replacements

Apply one carefully reviewed change across chosen writing.

Where to find it
Writing tools → Find & replace across writing

  1. Choose the project and documents to include. Enter the literal find and replacement text, with Match case if appropriate.
  2. Preview the changes. Review the matching document names, occurrence counts and before/after text.
  3. Apply the batch only when the preview is correct. The operation changes the selected documents together.
  4. Use the saved operation’s Undo when necessary. Atlas refuses that undo if a later edit changed the affected documents, protecting newer writing.
What you should see

A project-wide change has a review step and a guarded recovery path.

Helpful details

  • Generated citations, bibliography text, note bodies and code are excluded.
  • Up to ten batch snapshots are retained. Make a full backup before a very large revision.

Details, tags and custom properties

Describe writing with only the fields you need.

Where to find it
Document details; Writing tools → Custom document properties

One search across the library

Find writing, cards, projects, events, references and indexed source pages.

Where to find it
Ctrl K; Find anything button

  1. Press Ctrl K and enter words or a quoted phrase. Search includes writing text, titles, tags, custom properties and other library items.

What you should see

Helpful details

  • Ctrl N creates a document; Ctrl Shift N creates a card. Quick commands are limited to the actions exposed by the current UI.

Connect ideas and resolve unclear connections.

Where to find it

  1. To make a stable internal link, use Link a note instead and choose the intended item. Atlas stores its ID so a rename does not break that connection.

What you should see

Connections remain useful as your library changes.

Helpful details

  • Use distinct titles when relying on typed wiki links; ID links are the most reliable choice when titles repeat.

Saving & recovery

Autosave, conflicts and safe closing

Understand whether your latest words are safely on disk.

Where to find it
Save status in the title bar; Ctrl S

  1. Watch for Unsaved changes, Saving… and Saved locally. Ctrl S asks Atlas to save now.
  2. Atlas uses atomic writes and previous-state recovery. Closing waits for saving rather than immediately discarding the current draft.
  3. If saving fails, keep the window open. Check storage access/free space, then retry. Use Export draft to rescue writing if necessary.
  4. If a conflicting external edit is detected, Atlas rejects the overwrite. Preserve the draft and compare the external library copy before choosing what to keep.

What you should see

Helpful details

  • Avoid editing library JSON outside Atlas while it is open.
  • Revision history, daily checkpoints and full backups serve different purposes.

Format notes and limits

  • Unexpected OS shutdown/storage failure is not a substitute for a second-drive backup.

Saving & recovery

Backup health, preview and restoration

Protect the complete library and test the recovery path.

Where to find it
Writing tools → Backup & recovery

  1. Review missing attachments, free space, revision/daily checkpoint counts and recorded complete backups.
  2. The health message identifies missing files, no available complete backup, or an archive older than seven days. Archive availability is not a new integrity check: use Preview a backup to verify its current contents.
  3. Choose Create verified backup and save a .folio archive, preferably on a separate drive. It contains writing, events, references, attachments, annotations, history, templates, indexes and imported styles.
  4. Choose Preview a backup and select the archive. Atlas verifies it and shows the contents before you commit to restoration.
  5. Choose Restore separate copy only when you want to open a new restored library. The current library remains on disk, and the archive is checked again for changes.
  6. Review the restored writing and source files. Use Choose library folder when returning to another saved library.
What you should see

A portable, verified copy can recover more than the current text document.

Helpful details

  • Missing attachment bytes cause backup to fail rather than silently omit sources.
  • Daily JSON checkpoints refer to the original attachment directory; they are not complete portable archives.

Format notes and limits

  • Restoration is bounded to 512 MB compressed and 1 GB expanded. Libraries/backups are not encrypted by Atlas.

Saving & recovery

Troubleshooting and known limits

Choose the right recovery step when something does not behave as expected.

Where to find it
Help & Learning; Backup & recovery

  1. Cannot find writing? Check the project, sidebar query, pinned/card filters, archive status and Trash before assuming it was lost.
  2. Save failure/conflict? Keep the window open, export the draft if needed, check storage access/free space and preserve both versions before resolving an external conflict.
  3. No dictation audio? Select the intended Windows input device, allow microphone access for desktop apps, then try a short recording. Audio-file transcription can help distinguish device problems from recognition problems.
  4. No source-content results? Index the file first; enable the correct OCR language for a scan. Check the source itself when recognition gets words/numbers wrong.
  5. Export looks different? Verify format limits, scope/order and preset. Use Word for native note parts or HTML/PDF for rendered equations; specialist publishing may need another layout application.
What you should see

A problem has a concrete next check and a way to protect the writing.

Helpful details

  • The full installer includes speech/OCR/runtime resources. Reinstall the full package if the speech pack is missing. Uninstall keeps your library.
  • For any reported bug, note the app version, action, expected result and actual message without sharing private writing unnecessarily.

Format notes and limits

  • Maximum validation limits are not demonstrated performance guarantees. Long-session, extreme-size, low-memory, multiple-display and sudden-OS-shutdown testing is incomplete. No live coauthoring, direct Zotero sync, full TeX compiler or app encryption is included.
